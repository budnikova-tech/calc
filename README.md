# Калькулятор прибыли на маркетплейсах

Статический калькулятор юнит-экономики для продавцов на маркетплейсах.

Учитывает:

- процент выкупа и возвраты;
- прямую и обратную логистику;
- комиссию, рекламу и себестоимость;
- постоянные расходы, налоги и списания;
- точку безубыточности, минимальную цену и безопасную скидку;
- пользовательские сценарии изменения цены, заказов, комиссии и рекламы.

Для локального запуска откройте `index.html` в браузере.

Проверка финансовых формул:

```powershell
node --test tests/calculator.test.js
```
